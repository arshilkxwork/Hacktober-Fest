# DecisionTrail

Recover the engineering decisions nobody wrote down. DecisionTrail reads public
project discussions, extracts the decisions made in them with their reasons and
the alternatives that were rejected, links them to the code they are about, and
surfaces them when a pull request touches that code.

Built for Hacktoberfest 2026 Hack Day Sonipat, Problem 06. Setup and usage
instructions arrive with the first feature PR.
